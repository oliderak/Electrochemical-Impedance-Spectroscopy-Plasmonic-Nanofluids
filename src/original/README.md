# Source-Code Provenance

The repository build was based on two MATLAB scripts supplied with the thesis materials:

- Original acquisition script: `medicioncapacitancia.m`.
- Original impedance script: `impedancia.m`.

The English-language implementations are provided in:

- `src/acquisition/acquire_lockin_sweep.m`
- `src/analysis/calculate_complex_impedance.m`
- `src/visualization/plot_impedance_results.m`

The original files are not duplicated here because the repository is intended to keep its executable code and documentation in English. The original uploaded files remain the source reference for the implementation.
