## Relationship to This Repository

This software repository contains MATLAB implementations associated with the research methodology described in the thesis, including:

- Lock-in amplifier frequency-sweep data acquisition.
- Complex impedance calculation.
- Electrical impedance visualization.
- RC and RCR reference circuit simulations.
- Measurement-cell equivalent circuit simulations.

The software is organized independently to facilitate execution, analysis, and reproducibility.
